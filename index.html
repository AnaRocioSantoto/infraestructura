Fundamentos de Enrutamiento IP

El enrutamiento es el proceso por el cual un router reenvía paquetes IP hacia redes de destino utilizando la coincidencia más larga de prefijo (longest match) en la tabla de enrutamiento. La diferencia fundamental entre el enfoque estático y dinámico radica en el método de descubrimiento y mantenimiento de rutas .

Configuración Manual

Enrutamiento Estático

Las rutas son creadas explícitamente por el administrador de red. Ideal para redes pequeñas, conexiones de última milla (rutas por defecto) o enlaces de respaldo.

  • Cero sobrecarga de ancho de banda y procesamiento .
  • Mayor control y seguridad topológica .
  • Inviable para redes de gran tamaño sin automatización .
Topología Fija / Manual
Automatizado

Enrutamiento Dinámico

Los routers ejecutan protocolos que intercambian información de red periódicamente o ante eventos para aprender vecindades y recalcular rutas óptimas ante fallos.

  • Alta escalabilidad y convergencia automática.
  • Descubrimiento automático de vecinos y subredes.
  • Consume procesamiento de CPU, memoria y ancho de banda.
Red Adaptativa / Autorecuperable

¿Qué es la Distancia Administrativa (AD)?

La Distancia Administrativa (AD) es el valor de confiabilidad asignado a una fuente de información de enrutamiento. Varia entre 0 y 255, donde un valor menor indica mayor confiabilidad. Cuando un router aprende la misma red de destino desde dos fuentes o protocolos distintos, la ruta con la AD más baja es la única que se instala en la tabla de enrutamiento.

Aplicación Práctica: Ruta Estática Flotante (Floating Static Route)

Las rutas flotantes aprovechan la Distancia Administrativa para crear **enlaces de respaldo automáticos**. Configurando una ruta estática con una AD mayor que la del protocolo primario (por ejemplo, AD = 120 frente a OSPF AD = 110), la ruta permanece oculta y solo se activa si el protocolo primario falla. 

! Ruta Primaria aprendida por OSPF (AD = 110)
! Ruta Estática Flotante de Respaldo hacia ISP Backup con AD = 130 (Superior a OSPF 110)
R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.2 130

Clasificación de Protocolos Dinámicos

Los protocolos dinámicos se organizan jerárquicamente según su ámbito de dominio (Sistema Autónomo) y el tipo de algoritmo subyacente.

Por Ámbito de Operación

IGP (Interior Gateway Protocols)

Utilizados para enrutamiento dentro de un mismo dominio administrativo o empresa (ej. OSPF, EIGRP, RIP).

EGP (Exterior Gateway Protocols)

Diseñados para intercambiar información de enrutamiento entre Sistemas Autónomos distintos (ej. BGP-4).

Por Naturaleza Algorítmica

Vector Distancia (Distance Vector)

Comparte la tabla de enrutamiento con vecinos directos (enrutamiento por rumor). Algoritmo Bellman-Ford.

Estado de Enlace (Link-State)

Cada router construye un mapa completo de la red (LSDB) y calcula el árbol de caminos cortos (SPF/Dijkstra).

Vector Distancia Avanzado / Híbrido

Combina la rapidez del estado de enlace con la simplicidad del vector distancia (ej. EIGRP con DUAL).

1. Historia y Versiones de RIP

RFC 1058 / RFC 2453

RIPv1 (Classful)

Lanzado en 1988. Broadcast (`255.255.255.255`). No envía la máscara de subred en las actualizaciones, impidiendo VLSM y CIDR.

RIPv2 (Classless)

Soporta VLSM, resumen manual y autenticación (MD5). Envía actualizaciones mediante Multicast (`224.0.0.9`).

RIPng (Next Gen)

Versión adaptada para IPv6. Utiliza el grupo Multicast `FF02::9` y puerto UDP 521. Elimina la autenticación propia, delegándola a IPsec.

2. Mensajes, Algoritmo y Métrica

Algoritmo Bellman-Ford

Calcula el camino óptimo evaluando únicamente el número de saltos (*Hop Count*)[cite: 107, 108]. Límite máximo de 15 saltos (16 = Red inalcanzable/infinito). Presenta convergencia lenta e implementa técnicas para prevenir bucles como *Split Horizon* y *Poison Reverse*.

Tipos de Mensajes RIP

  • Request: Solicitada al arrancar la interfaz para pedir la tabla a los vecinos.
  • Response: Envío de la tabla periódicamente cada 30 segundos o por cambio de estado.

3. Comandos de Configuración en Cisco IOS

R1# configure terminal
R1(config)# router rip
R1(config-router)# version 2
R1(config-router)# no auto-summary
R1(config-router)# passive-interface GigabitEthernet0/0
R1(config-router)# network 192.168.10.0

R1(config-router)# exit

1. Historia y Versiones de OSPF

Estándar Abierto IETF

OSPFv2 (IPv4)

Definido en RFC 2328. Diseñado para enrutamiento IPv4 sin clase (Classless). Soporta diseño jerárquico por áreas (Área 0 Backbone).

OSPFv3 (IPv6)

Definido en RFC 5340. Soporta IPv6 nativo y arquitecturas Dual-Stack mediante Address Families. Opera independientemente del direccionamiento de red.

2. Mensajes, Algoritmo Dijkstra y LSDB

Algoritmo SPF (Shortest Path First) / Dijkstra

Cada router intercambia anuncios de estado de enlace (LSA) para construir una base de datos topológica idéntica (LSDB) dentro del área[cite: 34, 60]. Ejecuta Dijkstra para obtener un árbol sin bucles hacia cada destino. Métrica = Costo basado en ancho de banda.

Paquetes de Control OSPF

1. Hello: Descubrimiento de vecinos.
2. DBD: Resumen de LSDB.
3. LSR: Solicitud de LSA específicosa.
4. LSU: Envío de LSA actualizadosa.

3. Comandos de Configuración en Cisco IOS

R1# configure terminal
R1(config)# router ospf 10
R1(config-router)# router-id 1.1.1.1
R1(config-router)# network 10.0.0.0 0.0.0.255 area 0
R1(config-router)# passive-interface GigabitEthernet0/0
R1(config-router)# auto-cost reference-bandwidth 10000
R1(config-router)# exit

1. Historia y Versiones de EIGRP

Cisco Proprietary / RFC 7868 Informacional

EIGRP Clásico (AS)

Introducido por Cisco en 1992 como evolución de IGRP. Configuración mediante proceso de Sistema Autónomo (`router eigrp AS`) para IPv4 e IPv6 por separado.

Named EIGRP

Estructura de configuración moderna unificada bajo un único nombre de instancia, permitiendo gestionar IPv4, IPv6 y parámetros de interfaz en un solo bloque.

2. Algoritmo DUAL, Tablas y Paquetes RTP

Algoritmo DUAL (Diffusing Update Algorithm)

Garantiza rutas sin bucles y convergencia inmediata. Mantiene un **Sucesor** (ruta primaria) y precalcula un **Sucesor Factible** (backup libre de bucles) mediante la Condición de Factibilidad ($RD < FD$)[cite: 193].

Paquetes EIGRP (Protocolo RTP)

Hello: Saludo y mantenimiento.
Update: Cambios parciales.
Query: Consulta de respaldo.
Reply: Respuesta a consulta.

3. Comandos de Configuración en Cisco IOS (Named EIGRP)

R1# configure terminal
R1(config)# router eigrp EMPRESA
R1(config-router)# address-family ipv4 unicast autonomous-system 100
R1(config-router-af)# network 172.16.0.0 0.0.255.255
R1(config-router-af)# af-interface GigabitEthernet0/0
R1(config-router-af-interface)# passive-interface
R1(config-router-af-interface)# exit
